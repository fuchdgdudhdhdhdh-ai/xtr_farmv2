# Раздай звёзды! — версия для Render

## Что внутри
- `index.html` — игра. Первые 30 кликов не вызывают счёт; после 30-го при 4+ кликах за последнюю секунду запрашивается счёт Telegram. Сумма счёта у каждого игрока своя (по умолчанию 50 Stars, меняется ссылкой от админа). Кнопка «🎁 Награды» слева под прогрессом: награды, реф-ссылка, баланс и вывод.
- `server.js` — Express-сервер: API игры + бот-команда `/admin`.
- `package.json` — зависимости и команда запуска.

## Настройка Render
Создайте **Web Service** из GitHub-репозитория с этим проектом.
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`

В Environment добавьте:
- `BOT_TOKEN` — токен бота из @BotFather.
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из 32–64 символов (латинские буквы и цифры).
- `OWNER_ID` — ваш числовой Telegram ID (узнать у @userinfobot). Вы — главный админ: управляете админами, получаете уведомления о наградах и выводах.
- `MINIAPP_LINK` — ссылка на ваш Mini App без параметров, например `https://t.me/ИМЯ_БОТА/ИМЯ_APP` (Direct Link) или `https://t.me/ИМЯ_БОТА` (Main Mini App). К ней добавляется `?startapp=...`. Эта же ссылка показывается игрокам как реферальная.
- `DATA_DIR` — папка для базы (`db.json`). По умолчанию `./data`.

⚠️ **Хранение данных.** Ссылки, админы, балансы и заявки лежат в файле `db.json`. На бесплатном Render диск **стирается при каждом деплое и перезапуске**. Чтобы данные не пропадали: подключите Persistent Disk (платный тариф), смонтируйте его, например, в `/var/data` и задайте `DATA_DIR=/var/data`. Иначе после деплоя все созданные ссылки/админы/балансы обнулятся.

После деплоя откройте `https://ВАШ-СЕРВИС.onrender.com/health` — должно вернуться `{"ok":true}`.

## Установка Telegram webhook
Теперь нужен ещё `callback_query` (кнопки админ-панели). Переустановите webhook:

```powershell
$token = "ТОКЕН_БОТА"
$domain = "ВАШ-СЕРВИС.onrender.com"
$secret = "ВАШ_TELEGRAM_WEBHOOK_SECRET"

$body = @{
  url = "https://$domain/api/telegram-webhook"
  secret_token = $secret
  allowed_updates = @("message", "pre_checkout_query", "callback_query")
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri "https://api.telegram.org/bot$token/setWebhook" `
  -ContentType "application/json" `
  -Body $body
```

Проверка: `Invoke-RestMethod -Uri "https://api.telegram.org/bot$token/getWebhookInfo"`.

## Подключение Mini App
В @BotFather настройте Menu Button или Main Mini App с адресом Render. Для ссылок вида `https://t.me/бот/app?startapp=...` создайте Direct Link Mini App командой `/newapp`.

## Команда /admin
Напишите боту `/admin` (работает в личке у владельца и добавленных админов):
- **➕ Создать ссылку** — введите сумму (1–10000 Stars), бот пришлёт ссылку. Игрок, открывший игру по ней, будет получать счёт на эту сумму, пока не перейдёт по другой такой ссылке.
- **📋 Ссылки** — последние ссылки, число открытий, удаление. Обычные админы видят только свои.
- **👥 Админы** (только владелец) — добавить по числовому ID / убрать. Админы могут только создавать ссылки.
- **💸 Заявки на вывод** (только владелец) — также каждая новая заявка приходит вам сразу с кнопками «Выплачено» / «Отклонить». При отклонении звёзды возвращаются на баланс игрока.

Новые награды (🧸 за 10+ кликов/сек, 🧸 за 8 уровень, 🌹 за 15 уровень) тоже приходят вам сообщением с кнопкой «Выдано» — подарки отправляете вручную.

## Рефералы
Игрокам показывается одна общая ссылка (`MINIAPP_LINK`), поэтому начисление за рефералов пока не срабатывает. Серверная часть готова: если открыть игру по `?startapp=ref_ID_ПРИГЛАСИВШЕГО`, новый игрок привязывается к пригласившему, и тот получает 50% от каждой оплаты Stars реферала на баланс. Для персональных ссылок в `/api/me` достаточно вернуть `refLink: MINIAPP_LINK + '?startapp=ref_' + u.id`.

## Важно
- Не добавляйте `BOT_TOKEN` в HTML, GitHub или сообщения. Если токен утёк — перевыпустите в @BotFather.
- Сервер теперь раздаёт только `index.html`, а не всю папку (иначе была бы доступна база).
- Достижения (кликов/сек, уровни) считаются на устройстве игрока, поэтому ловкий пользователь может их подделать — смотрите заявки перед выдачей подарков.
- Если меняете Environment Variables, сделайте новый Deploy.
- На бесплатном тарифе сервис засыпает; первый запуск после паузы может занять время.
